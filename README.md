# TASK 05 – Ecommerce Return Rate Investigation

## 1. Problem Statement

Investigate factors influencing product return behavior in an e-commerce environment using statistical analysis and customer analytics.

---

## 2. Dataset Description

Dataset: returns_sustainability_dataset.csv

Features:

* Order information
* Product details
* Customer details
* Return behavior
* Sustainability indicators

Total Records: ~5000

Total Columns: 23

---

## 3. Statistical Methods

* Data Cleaning
* Descriptive Statistics
* Correlation Analysis
* Outlier Detection (IQR, Z-score)
* Hypothesis Testing (T-Test)
* Customer Segmentation

---

## 4. Return Findings

Key return drivers were analyzed through:

* Product Category
* Product Price
* Delivery Duration
* Discounts
* Customer Behavior

## 5. Visual Insights

Visualizations Included:
