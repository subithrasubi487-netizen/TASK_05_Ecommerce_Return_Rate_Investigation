# Return Investigation Report

## Introduction

This project analyzes e-commerce product return behavior using statistical and exploratory data analysis techniques to identify the factors influencing returns.

---

## Objective

To investigate product return patterns and provide recommendations that help reduce operational losses and improve customer experience.

---

## Dataset Overview

Dataset:
returns_sustainability_dataset.csv

Records:
Approximately 5000 rows

Features:
23 columns

Important variables:

* Product Category
* Product Price
* Discount Applied
* Return Status
* Days to Return
* Order Value
* Return Cost

---

## Statistical Analysis

Performed:

* Data Understanding
* Descriptive Statistics
* Return Pattern Investigation
* Outlier Analysis
* Hypothesis Testing
* Customer Segmentation

Methods Used:

* Mean
* Median
* Standard Deviation
* Quartiles
* Correlation Analysis
* IQR
* Z-Score
* T-Test

---

## Findings

* Return rates varied across product categories.
* Product pricing influenced return patterns.
* Delivery duration affected customer return behavior.
* Discounts showed association with return trends.
* Customer groups displayed different return characteristics.

---

## Business Insights

* High-return products require monitoring.
* Delivery operations can impact return reduction.
* Customer segmentation supports targeted improvements.

---

## Recommendations

1. Improve delivery timelines.
2. Monitor repeat-return customers.
3. Reduce unnecessary discount campaigns.
4. Improve product quality controls.
5. Focus on high-risk categories.

---

## Conclusion

Statistical analysis identified return patterns and provided business actions that may reduce operational losses and improve customer satisfaction.
